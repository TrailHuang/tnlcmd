# v0.1.8 发布说明

发布日期：2026-11-27
上一版本：v0.1.7（2026-11-26）

本版本聚焦**可观测性**与**输入健壮性**：新增集中式调试日志（环境变量开关，默认零开销）、CI 流水线与 IPv4/IPv6/MAC 地址参数校验，重写 Telnet 输入过滤器统一处理变长序列，并新增单行长度限制与读超时配置。同时修复多项并发竞争、审计日志缺陷及子视图帮助显示问题。共 12 个提交，35 个文件变更（+3553 / -1354 行，不含本发布说明），全量通过 `go vet` 与 `go test -race`。

## 🎯 亮点

### 调试日志（internal/debuglog）

新增集中式调试日志能力，用于追踪"重启后用户输入无响应"等难以静态复现的故障：

- 通过环境变量开启，默认关闭且对运行时零开销（热路径由 `Enabled()` 短路）
- `TNLCMD_DEBUG`：级别控制，`off` / `debug` / `trace`（trace = Debug + Trace 全量输出）
- `TNLCMD_DEBUG_FILE`：日志文件路径（追加模式）；为空时输出到标准错误
- 结构化输出：时间戳、级别、事件类型、组件名称及调用方键值对（如 `n=…`、`state=…`）
- 覆盖输入解析、行处理、服务生命周期等关键路径

```bash
# 输出到 stderr
TNLCMD_DEBUG=trace ./your-app

# 输出到文件
TNLCMD_DEBUG=debug TNLCMD_DEBUG_FILE=/tmp/tnlcmd.log ./your-app
```

### IP/IPv6/MAC 地址参数校验

新增 6 类占位符参数节点（`pkg/types` 公开，命令注册与补全、校验全链路生效）：

| 节点类型 | 占位符 | 说明 |
|---|---|---|
| `NodeTypeIPV4` | `A.B.C.D` | IPv4 地址 |
| `NodeTypeIPV4Prefix` | `A.B.C.D/M` | IPv4 前缀（掩码 0–32） |
| `NodeTypeIPV6` | `X:X::X:X` | IPv6 地址 |
| `NodeTypeIPV6Prefix` | `X:X::X:X/M` | IPv6 前缀（掩码 0–128） |
| `NodeTypeMAC` | `M:A:C` | MAC 地址（冒号分隔） |
| `NodeTypeMACPrefix` | `M:A:C/M` | MAC 前缀 |

- 非法输入（如 `256.1.1.1`、`10.0.0.0/33`、IPv6 带 zone）返回具体校验错误提示
- 补全导航按固定优先级排序，同层多参数节点时结果稳定

### Telnet 输入过滤器重写（internal/session）

三条读取路径（命令行、密码、分页按键）共用一套输入过滤器，状态跨读取批次保持：

- 正确处理变长 Telnet IAC 协商、子协商、ANSI 光标序列与 UTF-8 全角问号
- 未闭合序列超长（>64 字节）时回退正常态，防止状态机永久挂起
- 支持 ESC[1;5D 等带修饰符的序列与 Home/End/Delete 变体

### 输入边界控制

新增两项配置（均可通过 `SetConfig` 设置，下次 `Start` 生效）：

- `MaxLineLength`（配置键 `maxlinelength`）：单行输入字节上限，默认 4096；超限时提示 `% Line too long` 并丢弃该行
- `ReadTimeout`（配置键 `readtimeout`）：会话读超时（支持 Go duration 语法如 `"30s"`），0 表示不超时；认证阶段另有独立超时

## 🔧 重构与修复

- **修复启动失败时审计资源泄漏**：`server.Start` 失败后回收文件句柄与后台清理 goroutine
- **修复并发停止的 WaitGroup 竞态**：`stopping` 置位与 `wg.Add` 收敛到同一临界区
- **修复并发 `SetConfig` 与活动会话的数据竞争**：`Start` 时对配置取快照，运行期修改只作用于模板配置（下次 Start 生效）；`port`/`auditlogfile`/`auditlog` 运行中修改被明确拒绝
- **修复跨天审计日志未归档**：首次写入时检测日期变化并滚动归档
- **修复审计 logger 覆盖进程全局默认 logger**：审计改用专用 logger，不再污染全局
- **修复超长行拒绝后回车误吞**：CRLF 残留的 LF 仅在确认时跳过，LF-only 客户端的真实回车不再丢失
- **修复 ModeSwitch 节点误入参数校验**：视图切换节点不再被计为命令参数
- **修复子视图下 ? 帮助丢失视图切换命令**：interface 等子模式下 `?` 恢复显示 `configure` 等切换命令，数据来源与 Tab 补全、跨模式执行同源（根模式），并排除当前所在视图
- **重构命令树与模式上下文**：移除冗余代码与双树设计（平面表 + 树合并为单一命令树来源）
- 移除 completer 中冗余的 `walkExact` 导航函数

## 📦 升级说明

### 配置项变更

| 配置项 | 变更 |
|---|---|
| `MaxLineLength` / `ReadTimeout` | 新增，默认 4096 / 0（不超时） |
| `AuditLog` 运行中修改 | 行为变更：已启动服务中修改被明确拒绝（仅 Start 前设置有效） |
| `AuditLogFile` 运行中修改 | 同上 |
| `IdleTimeout` | 保持唯一热更新配置项不变 |

### 兼容性

- Go 1.24+，零第三方依赖
- 命令注册 API 签名不变；`SetConfig` 快照语义对既有单线程使用方透明
- 调试日志默认关闭，无环境变量时行为与 v0.1.7 一致
